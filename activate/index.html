Trambustissimo / desktop licences

Offline activation

Activate a VST3 instrument or standalone application without connecting the music computer to the Internet.

1. Create a request on the music computer

Open the product's LICENSE & DEVICES panel. Under Offline activation, save the computer request, or copy its computer code. Transfer the request to this Internet-connected device.

2. Verify your purchase

The key is sent only to the selected Trambustissimo activation service for verification with Gumroad. Nothing is saved to this browser, stored locally, or sent to a different product's service.
Download signed activation file

3. Import on the music computer

Transfer the downloaded .trmlicense file to the offline computer. Open LICENSE & DEVICES → Offline activation, import the file and choose Apply signed activation. The native plug-in verifies the signature and its binding to the computer. The computer can remain offline afterward.

Each purchase supports up to three registered computers. A new computer requires its own request and signed file. Licence release and other Gumroad account actions require access to the activation service.
